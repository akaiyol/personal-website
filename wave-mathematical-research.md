## 3. Mathematical mechanisms to evaluate

### Primary water: two viable paths

**A — repair the reduced hybrid.** Evolve depth `h` and horizontal momentum `q=hu` using conservative shallow-water equations:

`∂t h + ∂x q = 0`

`∂t q + ∂x(q²/h + gh²/2) = −gh ∂x b + F`

Here `u` is depth-averaged horizontal velocity, `b` bottom elevation, `g` gravity and `F` momentum forcing. Use a positivity-preserving finite-volume method and a CFL bound based on `|u|+sqrt(gh)`. Track breaking fronts and continuously generate sheets using the Thürey mechanism. This supplies compression and reflection but does not resolve vertical circulation; sheets remain a reduced approximation. Introducing a bottom profile must be explicit, not a hidden growth gradient.

**B — side-view PIC/FLIP.** Represent water with particles coupled through a two-dimensional staggered velocity grid. Advect material, apply gravity, enforce solids and project velocity:

`∇²p = (ρ/Δt) ∇·u*`, then `u_new = u* − (Δt/ρ)∇p`.

`u*` is intermediate velocity; `p` pressure; `ρ` density. Air/free-surface and solid boundary conditions are essential. PIC takes interpolated grid velocity; FLIP adds the grid velocity change to particle velocity. A blend trades dissipation against noise. This permits overhangs without separate pre-shaped primary wave strips, but requires particle/grid transfers, reconstruction and measured performance. These equations describe a candidate, not implemented functionality.

### Foam and turbulence

The Ihmsen generation model combines normalized energy `I_k`, converging relative-motion potential `I_ta` and crest potential `I_wc`: `n_d = I_k(k_ta I_ta + k_wc I_wc) Δt`. This is a source model; our thresholds and units would need calibration. It offers a causal replacement for emitting a similar number of drops from every sheet point.

For procedural detail in a two-dimensional velocity field, use a scalar streamfunction `ψ`: `u_detail=(∂yψ,−∂xψ)`. Its divergence is zero analytically. Modulate `ψ` near solids before differentiation; simply multiplying velocity by a wall fade can introduce divergence. Noise sets coherent eddy detail, not the shape of each individual wave.

Reconstruct the visible surface from fluid occupancy or a smoothed particle density contour. Reveal selective tangential flow lines and dense foam patches in purple. Do not render all solver particles as confetti. Choose smoothing against the actual Braille cell size so it removes particle bumps without erasing overhangs and black hollows.

## 4. Proposed order and decision gates

Recommendation: evaluate **B, side-view PIC/FLIP**, before more crown tuning. It most directly addresses missing vertical circulation, primary-water contact and overturning. A is a lower-cost alternative if B fails the browser budget. This is a recommendation awaiting path selection, not a silent change to ADR 001.

1. Build a bounded standalone comparison experiment, keeping the current website and baseline available. Start from already disturbed water with directional excitation; test an impermeable right wall. No foam forks yet.
2. Require connected material, overhangs, wall-driven upward redirection and returning circulation with primary-water motion alone. Compare equal-duration runs at equal display size. Reject a model that still needs a scripted eruption to look forceful.
3. Measure particle count, grid resolution, pressure residual/divergence, volume drift, timestep sensitivity, frame cost and long-run stability. Set the browser budget from measurements rather than importing a demo's performance claim.
4. Add curvature/relative-motion/energy-driven foam. Compare generation maps to visible crests and contact. Check floating transport separately from ballistic spray and return.
5. Reconstruct and simplify at Braille resolution. Restore hierarchy, points, black cavities and selective contours. Evaluate three complete arrivals, a 60-second live run, desktop, mobile and reduced motion against `wave.md`.

If motion succeeds but visual character fails, refine reconstruction and stroke selection. If the curl or contact fails before rendering, revise the solver/boundaries rather than adding decorative claws. Stronger contrast cannot repair weak dynamics.
