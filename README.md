# Yolanda's personal website

I'm Yolanda, an Electrical and Computer Engineering student at the University of Waterloo. I enjoy product management, coding fun projects, and the arts.

This is my personal website: a terminal-inspired space for my background, work experience, and projects. It uses a black-and-purple palette, character artwork, a framed About Me gallery, and a vertical work timeline. A terminal-style command line handles navigation.

## Stack

- HTML for page structure and content.
- CSS for responsive layouts, frames, and animations.
- Vanilla JavaScript for terminal navigation, gallery interactions, and timeline year selection.

The website is static, with no frontend framework, backend, or API required. An optional Python/Pillow script generates Braille lettering; it is not needed to run the site.

## Local preview

From the repository directory, run:

```sh
python3 -m http.server 8765
```

Open http://localhost:8765 in your browser.
