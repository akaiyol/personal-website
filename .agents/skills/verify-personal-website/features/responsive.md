# Responsive layout

Run `responsive` after shell or About sizing changes. The helper drives five routes at 1920, 1470, 1280, 1024, 820, 801, 800, 701, 700, 600, 390 and 320px widths, with varied viewport heights.

Check document overflow; shell/footer agreement; caterpillar right edge, header and footer clearance; centred resting photo bounds; gacha full story width; horizontal character-card containment. Resize during an actual roll and verify all strips settle correctly. On phones, four reels remain above the Roll control and result labels use two readable columns.

Review screenshots at desktop, tablet and narrow sizes, including scrolled gallery, open character card and long gacha labels. Geometry assertions do not establish visual quality. Horizontal scrolling within the photo rail is intentional; document overflow is not.
